Contexto de trabajo - sesion 2026-04-15
=======================================

Objetivo principal acordado
---------------------------
Migrar el proyecto de Google Sheets/localStorage a una arquitectura con backend + MongoDB.


Decisiones tomadas hoy
----------------------
1) Arquitectura
- Frontend no se conecta directo a MongoDB.
- Se usara backend (Node + Express + Mongoose) con API REST.
- MongoDB sera la fuente de verdad.
- localStorage puede quedar como cache/offline temporal.

2) Colecciones recomendadas
- clientes
- citas
- historial_servicios
- contactos_log
- usuarios

3) Endpoints base recomendados
- /api/clientes (GET, GET:id, POST, PUT/PATCH:id, DELETE:id)
- /api/citas (GET, GET:id, POST, PATCH:id, DELETE:id)
- /api/historial (GET por placa, GET:id, POST, PATCH:id, DELETE:id opcional)
- /api/contactos-log (GET, POST, DELETE:id)
- /api/auth (login, logout, me) y /api/usuarios (admin)

4) Indices clave
- clientes: placa unique
- citas: unique compuesto (fecha, hora, espacio)
- historial_servicios: index en placa y fechaActual
- contactos_log: index en fechaContacto

5) Estrategia de implementacion
- Recomendado: backend primero, luego frontend por vertical slices.
- Orden recomendado:
  - Slice 0: infraestructura de API en frontend
  - Slice 1: clientes
  - Slice 2: citas/agenda
  - Slice 3: historial
  - Slice 4: contactados
  - Slice 5: auth


Funciones frontend identificadas para migracion
