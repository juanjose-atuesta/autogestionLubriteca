====================================================================
1) OBJETIVO GENERAL DE LOS CAMBIOS
====================================================================

Se implementaron dos entregables principales:

1. Nueva seccion en el navegador lateral llamada "Citas programadas".
2. Nueva vista/tab para listar citas obtenidas desde getCitas() con:
   - columnas solicitadas: nombre, telefono, placa, servicio, espacio, fecha, hora, notas
   - filtro por: nombre, espacio, servicio, hora, fecha, placa
   - boton de notas por fila (abre un cuadro con las notas)
3. Badge (circulo) amarillo en el item lateral "Citas programadas" que muestra el total de citas.

Adicionalmente, se conecto el refresco de esta vista/badge a los flujos que ya existian en la app
(login, sync, crear/eliminar cita, refresco periodico), para que no se quede desactualizada.

3.3) js/listaCitas.js (NUEVO)
--------------------------------------------------------------------
QUE CAMBIE:
- Se creo un modulo nuevo para concentrar TODA la logica de la lista de citas programadas.
- Incluye:
  - normalizacion visual de espacios (carcamo, gato_hidraulico, gato_electrico)
  - modal simple de notas via alert
  - actualizacion de badge lateral de citas
  - funcion principal de render con filtro + orden + stats + tabla
  - funciones de UI de filtro/limpiar

POR QUE:
- Pediste que se pudiera renderizar pagina y funcionalidades desde una sola funcion en un archivo nuevo.
- Se centralizo la logica en renderListaCitasProgramadas(filtro), y las funciones auxiliares solo apoyan ese flujo.

CODIGO COMPLETO:
```js
function formatoEspacioCita(space) {
  const valor = String(space || '').trim();
  const etiquetas = {
    carcamo: 'Cárcamo',
    gato_hidraulico: 'Gato Hidráulico',
    gato_electrico: 'Gato Eléctrico'
  };
  return etiquetas[valor] || valor;
}

function mostrarNotasCitaProgramada(notes) {
  const textoNotas = String(notes || '').trim();
  alert(textoNotas || 'Esta cita no tiene notas.');
}

async function actualizarBadgeCitasProgramadas() {
  const badge = document.getElementById('nav-badge-citas-programadas');
  if (!badge) return;
  const citas = await getCitas();
  badge.textContent = Array.isArray(citas) ? citas.length : 0;
}

async function renderListaCitasProgramadas(filtro = '') {
  const tbody = document.getElementById('listaCitasProgramadas');
  if (!tbody) return;

  const empty = document.getElementById('emptyCitasProgramadas');
  const tabla = document.getElementById('tablaCitasProgramadas');
  const stats = document.getElementById('statsCitasProgramadas');

  const todas = await getCitas();
  const badge = document.getElementById('nav-badge-citas-programadas');
  if (badge) badge.textContent = Array.isArray(todas) ? todas.length : 0;
  const filtroNormalizado = String(filtro || '').trim().toUpperCase();

  let citas = Array.isArray(todas) ? todas : [];
  if (filtroNormalizado) {
    citas = citas.filter(cita => {
      const nombre = String(cita.name || '').toUpperCase();
      const espacio = formatoEspacioCita(cita.space).toUpperCase();
      const servicio = String(cita.service || '').toUpperCase();
      const hora = String(cita.hour || '').toUpperCase();
      const fecha = String(cita.date || '').toUpperCase();
      const placa = String(cita.plate || '').toUpperCase();

      return nombre.includes(filtroNormalizado) ||
        espacio.includes(filtroNormalizado) ||
        servicio.includes(filtroNormalizado) ||
        hora.includes(filtroNormalizado) ||
        fecha.includes(filtroNormalizado) ||
        placa.includes(filtroNormalizado);
    });
  }

  citas.sort((a, b) => `${String(a.date || '')} ${String(a.hour || '')}`.localeCompare(`${String(b.date || '')} ${String(b.hour || '')}`));

  const totalConNotas = (Array.isArray(todas) ? todas : []).filter(c => String(c.notes || '').trim()).length;
  stats.innerHTML = `
    <div class="db-stat-item"><span class="db-dot" style="background:#3b82f6"></span>${citas.length} mostradas</div>
    <div class="db-stat-item"><span class="db-dot" style="background:#14b8a6"></span>${totalConNotas} con notas</div>
    <div class="db-stats-total">${(Array.isArray(todas) ? todas : []).length} citas</div>`;

  tbody.innerHTML = '';
  if (!citas.length) {
    empty.style.display = 'block';
    tabla.style.display = 'none';
    return;
  }

  empty.style.display = 'none';
  tabla.style.display = '';

  citas.forEach(cita => {
    const tr = document.createElement('tr');

    const celdas = [
      String(cita.name || ''),
      String(cita.telephone || ''),
      String(cita.plate || '').toUpperCase().trim(),
      String(cita.service || ''),
      formatoEspacioCita(cita.space),
      String(cita.date || ''),
      String(cita.hour || '')
    ];

    celdas.forEach(valor => {
      const td = document.createElement('td');
      td.textContent = valor;
      tr.appendChild(td);
    });

    const tdNotas = document.createElement('td');
    const btnNotas = document.createElement('button');
    btnNotas.className = 'btn-edit';
    btnNotas.textContent = '📝 Notas';
    btnNotas.onclick = () => mostrarNotasCitaProgramada(cita.notes);
    tdNotas.appendChild(btnNotas);
    tr.appendChild(tdNotas);

    tbody.appendChild(tr);
  });
}

function filtrarListaCitasProgramadas() {
  renderListaCitasProgramadas(document.getElementById('buscadorCitasProgramadas').value);
}

function limpiarBuscadorCitasProgramadas() {
  const buscador = document.getElementById('buscadorCitasProgramadas');
  buscador.value = '';
  renderListaCitasProgramadas();
  buscador.focus();
}
```

4) APARTADO ESPECIAL — COMO IMPLEMENTE LA LISTA DE CITAS
====================================================================

La implementacion se hizo con una arquitectura simple y directa:

1) Fuente de datos unica:
   - Se usa getCitas() (asincrona) como fuente de verdad.
   - No se cachea localmente en esta capa para evitar inconsistencia visual.

2) Funcion principal de UI:
   - renderListaCitasProgramadas(filtro = '').
   - Esta funcion:
     a) trae datos (await getCitas()),
     b) normaliza filtro,
     c) aplica filtro multi-campo,
     d) ordena por fecha/hora,
     e) actualiza stats,
     f) actualiza badge lateral,
     g) pinta filas/empty state.

3) Filtro multi-criterio:
   - Se filtra por OR entre:
     name, space(formateado), service, hour, date, plate.
   - Se usa mayuscula para comparacion case-insensitive.

4) Formato del espacio:
   - El backend puede enviar carcamo/gato_hidraulico/gato_electrico.
   - Para UI legible se mapea a:
     Cárcamo, Gato Hidráulico, Gato Eléctrico.

5) Notas como boton:
   - En cada fila, en vez de texto plano, se crea boton "📝 Notas".
   - Click -> mostrarNotasCitaProgramada(notes) -> alert con contenido.
   - Si no hay notas, muestra mensaje de ausencia.

6) Integracion de navegacion:
   - seleccionarTab('citas-programadas') dispara render inmediato.
   - Esto evita que el usuario entre a una vista vacia esperando refresh.

7) Consistencia por eventos:
   - Login: actualiza badge.
   - Sync: actualiza badge + rerender si tab activo.
   - Crear/eliminar cita: actualiza badge + rerender si tab activo.
   - Timer global: mantiene data viva si tab activo.

8) Consistencia visual:
   - Se reutilizo estructura de Base de Datos:
     card-header, search-bar, db-stats, table-wrap, empty-state.
   - Se agrego badge lateral con patron de badges existentes.

5) RAZONES DE DISENO Y DECISIONES IMPORTANTES
====================================================================

- Se separo en archivo nuevo (js/listaCitas.js):
  para evitar mezclar responsabilidades con agenda.js/ui-tablas.js y facilitar mantenimiento.

- Se uso una funcion principal de render:
  simplifica la trazabilidad; cualquier cambio de UI de citas pasa por el mismo punto.

- Se actualiza badge desde render y desde eventos globales:
  doble seguridad para evitar desincronizacion del contador.

- Se mantiene el filtro al refrescar estando en tab activo:
  mejor UX (no borra lo que el usuario esta buscando).

- Se uso alert para notas:
  cumple el requerimiento de "saque un cuadrito" con implementacion minima y robusta.
  Si luego quieres, se puede migrar a modal custom del sistema para una UX mas elegante.
